# DragonGirlBackground

DragonGirlBackground 是一款适用于 Windows 商店版 Codex 桌面应用的本地背景插件。支持自选 PNG、JPEG 或静态 WebP 图片，并在原生设置中调整透明度、缩放、填充方式和位置。图片仅在本机读取和显示，需要 Node.js 24 或更高版本。
